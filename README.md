Entrevista a quien conoce el proceso, sección por sección, y devuelve el PRD completo: el documento que describe la aplicación antes de construirla.

## Instalarla

Abrí Claude Code y pedile:

> Instalá la skill prd-claude desde https://github.com/dbarrado/prd-claude: copiá la carpeta `prd-claude` dentro de la carpeta de skills de mi usuario (`~/.claude/skills`) y confirmame que la reconoce.

Después cerrá Claude Code y abrilo de nuevo. A mano: Code → Download ZIP, y copiá la carpeta `prd-claude` en `C:\Users\TU-USUARIO\.claude\skills\`.
